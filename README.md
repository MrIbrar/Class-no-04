# Python Practice – Dictionary & Set Exercises

This repository contains beginner-level exercises that demonstrate practical usage of **Python dictionaries and sets**. These exercises are ideal for new learners aiming to strengthen their understanding of basic data structures in Python.

---

## 🧾 Exercises Included

### 1. Word Meanings Dictionary

* Stores multiple meanings for words using a dictionary.
* Example:

  ```python
  {
    "table": ["a piece of furniture", "list of facts & figures"],
    "cat": "a small animal"
  }
  ```

### 2. Unique Subject Count for Classrooms

* Given a list of repeated subjects, determines how many **unique classrooms** are needed by converting the list to a `set`.

### 3. Student Marks Entry

* Accepts marks for 3 subjects from the user.
* Stores the subject names as keys and marks as values in a dictionary.

### 4. Store `9` and `9.0` Separately in a Set

* Demonstrates how Python handles equality of `9` (integer) and `9.0` (float).
* Shows two solutions:

  * Using **strings**
  * Using **tuples with type indicators** (e.g., `("int", 9)` and `("float", 9.0)`)

---

## 💡 Concepts Covered

* Python **dictionaries** (key-value mapping)
* Python **sets** (handling unique values)
* Type sensitivity in Python sets
* Dynamic input from the user
* Data organization and representation
